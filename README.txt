# 🌟 Mood Diary

Простое приложение для отслеживания ежедневного настроения на Python.

## 📋 Возможности

- ✅ Добавление записей о настроении
- ✅ Просмотр статистики
- ✅ Валидация ввода
- ✅ Сохранение в файл
- ✅ Конфигурация через .env

## 🚀 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/Shik1990/mood_diarly.git
cd mood_diarly

# Создать виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac

# Установить зависимости
pip install -r requirements.txt

# Настроить .env
cp .env.example .env
# Отредактировать .env своими значениями

# Запустить
python main.py
